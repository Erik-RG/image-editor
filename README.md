# PixelForge Studio

A dependency-free, responsive browser image editor.

## Features

- Open local images and export PNG files
- Brightness, contrast, saturation, grayscale, sepia, and hue controls
- Brush and text tools
- Responsive desktop and mobile layout

## Run

Open `index.html` directly, or serve the directory with:

```bash
python -m http.server 8000
```
